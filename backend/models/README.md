# AegisMail phishing text classifier

`phishing_text_classifier.joblib` is the trained TF-IDF plus Logistic Regression pipeline used by the backend. It was generated by `backend/training/train_phishing_classifier.py` using subject/body text from the six individual source CSVs described in [../data/README.md](../data/README.md). The aggregate CSV was excluded. The local training report records 81,888 unique rows after cleaning and a stratified 80/20 holdout. The report and source CSVs are intentionally not distributed.

The model is shared under CC BY-SA 4.0 as a conservative share-alike approach to distributing a trained model based on that dataset. Changes made: the data was cleaned, normalized, deduplicated, and used to fit a TF-IDF vectorizer and Logistic Regression classifier.
